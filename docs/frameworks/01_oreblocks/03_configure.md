# oreblocks, configuration that matters

The block size is a scientific choice, not a performance one. A truck load is
220 t; at the 10 m blocks a block model usually carries, one block is 2,700 t, so twelve consecutive
trucks would leave the same block at exactly the same grade and the stream would be a staircase with
a period nothing in the deposit put there. The synthetic lane uses 6 m blocks, 583 t, under three
loads, so the step is shorter than the shortest structure any claim rests on.

The economics are chosen so the pit is a real subset of the model. A pit that takes every block makes
the extraction sequence meaningless.
